## Problem



I often forget how much water I drink during the day. This application helps me record and manage my daily water intake.



## Features



- Create water logs

- View all logs

- Update existing logs

- Delete logs



## Tech Stack



- Node.js

- Express.js

- SQLite

- HTML

- CSS

- JavaScript
